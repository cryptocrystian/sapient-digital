# Sapient Digital — Clean Brand v2 Rebuild

This is a net-new marketing site, deliberately isolated from the antiquated root `app/` and `website/` trees. Nothing from those applications is imported.

## Run
```sh
cd site-v2
npm install
npm run dev
npm run typecheck
npm run build
```

## Foundation
- Worldview first: attention is abundant, authority is scarce; credible signals reinforce one another; marketing must respond to changing conditions.
- Brand: IMPOSSIBLE TO IGNORE. / Connected Marketing. Amplified Impact. / The Signal Effect.
- Disciplines: Digital PR, Strategic Content, SEO/AEO/GEO (always together).
- Operations: clearly scoped monthly programs; adaptive execution within the agreed scope; no client-facing credits.
- Technology: publicly describe purpose-built proprietary intelligence, without mentioning the separate SaaS venture or internal product names.
- Visual direction: Controlled Intensity; graphite #242424, charcoal #343434, off-white #F4F3EF, oxide orange #FF5A1F, rare volt #EFFF00.
- Current hero art is a CSS concept stand-in for the approved physical, industrial Signal Array; replace with an art-directed licensed/original cinematic render before public launch.

## Important release blockers
- Confirm the CTA destination and wire it to a real CRM-integrated form before launch (current mailto is a functional fallback only).
- Produce and integrate the final physical Signal Array visual and additional editorial photography/video; do not ship an all-CSS-only design.
- Implement responsive full navigation and all supporting pages (Signal Effect, Services, PR, Content, Search, About, Insights, Contact; Video optional).
- Only publish attributable and verified client outcome claims; no invented placements, ROI, testimonials, or composite KPI scores.
- Validate accessibility, reduced motion, SEO metadata, schema, analytics, and mobile/desktop performance.
- Decide deployment root only after reviewing this isolated branch. Existing live site remains untouched.

## Status
Initial hero + worldview + positioning + services + approach + proof architecture scaffolded as a fresh starting point. This is **not yet production ready**.
