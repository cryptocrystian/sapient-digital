# Pravado API Environment — Agency Config

`apps/api/.env.agency` extracted from Pravado's repo. Contains environment configuration that was used when AgencyOS consumed Pravado's backend directly.

**Activation note:** Sapient's activation architecture is API-based consumption, not shared backend. This env file is historical reference — AgencyOS will authenticate to Pravado's public API via API key once that API is built, not via these credentials.
